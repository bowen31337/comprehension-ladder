    How the comprehension ladder works

    The skill takes one thing you want to understand and shows it in one of four formats. Each format shows the same facts.

    The short version

    • There are four rungs: STE prose, a diagram, an interactive page and a narrated video.
    • The skill picks a rung and a strictness from your words. The default strictness is 80%.
    • It writes one outline first. All four rungs show that one outline.
    • It keeps every hedge and adds no facts.
    • A linter checks the form of the text. The video works without Manim.

    1From your words to a rung

    The skill reads your request for format words and a strictness. Type a request, or pick one below.

    skill loads?
    rung
    strictness
    sentence cap

    This page uses the rules in SKILL.md. The real decision to load the skill is a model judgment, so the first box is a rough guide only.

    2Strictness and the linter

    Strictness is a percent. It sets how close the prose is to full STE (Simplified Technical English). Move the slider. The page runs the same rules as ste-lint.py on the text below.

      Red = hard finding (it fails the lint). Dashed = advice only. Green = a hedge. The linter never flags a hedge, because confidence is content.

      3One outline, four forms

      Before it makes anything, the skill writes an outline: core claims, the mechanism, every hedge and one real example. Pick a rung. The outline stays the same. Only the form changes.

      OUTLINE · retry.diff (test input)

      1. Attempts go from 3 to 5.
      2. The wait is random. Its cap doubles from 0.5 s to 8 s.
      3. The client now also retries 429 and connection errors.
      4. The test fixture probably replaces time.sleep.
      5. The diff does not say why.

      4The video path

      A video needs a renderer, a voice and ffmpeg. The render script uses the first tool it finds. Set what your machine has.

      5The other rungs

      The skill made this page from the same outline as the three other rungs. Each one shows the same facts in a different form.

      Rung 4: an 89-second narrated video with 14 beats. The skill drew it with frames.py and the macOS say voice, with no installs. The captions come from the same beat lengths as the voice. The captions control in the player turns them on or off.

      Rung 1: STE prose Rung 2: diagram (SVG) The skill on GitHub

      !What this does not show

      • The linter checks form only. It cannot tell if an explanation is true. The outline and the two rules do that job.
      • The skill does not include the official STE dictionary, because ASD does not permit others to copy it. Word choice is a direction, not a checked rule.
      • A plain "explain X" may not load the skill. Claude often answers that kind of request directly.
      • Text for other agents to read is the job of the asd-ste100 skill, not this one.

      Source: SKILL.md and the scripts in this repository. The retry.diff outline is a test input, not a real change.
